## 4. 关键用例说明

### 4.1 计算内核
- 运价三模式（按重 10000kg×200km×60分=120000 分；按方；按趟）✅
- Decimal HALF_UP 进位（100.005 → 100.01）✅
- ETA 强制休息（480km/60km/h → 8.5h）✅
- 结算拆分（司机应付 60%，亏损时为 0）✅
- 风险分档（0 正常 / >0 提 / ≥35 警 / ≥60 险，封顶 100）✅
- 状态机非法迁移拒绝（pending 不可直达 delivered）✅

### 4.2 业务流程
- 运单全生命周期：创建 → 调度（车辆/司机占用检查）→ 跟踪上报 → 签收（自动生成结算）→ 取消 ✅
- 调度冲突：占用车辆再调度返回 422 ✅
- 幂等键：同 Idempotency-Key 重复请求返回同一结果 ✅
- 增量同步：since=0 返回全量版本；since=current 返回空变更 ✅
- CSV 导出：UTF-8 BOM，表头正确 ✅
- 客户有运单时禁止删除（409）✅

### 4.3 安全与权限
- 未认证统一 401；权限不足统一 403 ✅
- 五通道鉴权：Bearer / X-Token / Cookie / ?token= / X-Api-Key ✅
- reader 角色只读（写操作 403，用户/日志不可见）✅
- API Key：默认 tms.* 可读写；受限 perms 只读；吊销后立即失效 ✅
- 密码 SHA-256 存储；API Key 仅明文返回一次 ✅

## 5. 已知事项

- 演示数据口径：金额字段单位为「分」，前端按分展示（对接方注意换算）
- SQLite 单机部署适用于中小规模（日均千单级）；更大规模建议切换 PostgreSQL（数据层已隔离，替换成本低）
