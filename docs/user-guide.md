## 1. 系统简介

## 3. 快速上手：开一张运单

1. 登录后进入「运单管理」→「新建运单」，选择客户、线路，填写货物/重量/体积/报价（单位：分），创建后状态为「待调度」。
2. 在运单列表点「调度」，选择空闲车辆与司机，确认发车 → 状态变「运输中」，系统自动计算 ETA。
3. 在途期间可在「运单管理」追加跟踪点，或在「在途跟踪」页按运单号查看轨迹。
4. 到达后点「签收」，填写签收人 → 状态变「已签收」，并在「财务结算」自动生成结算单（司机应付 60% 拆分）。
5. 财务在「财务结算」核对金额后点「结清」。

## 4. 页面说明（12 页）

- 工作台：今日运单/待调度/运输中/已签收/本月毛利/预警数 KPI 与最近运单
- 运单管理：筛选（状态/关键字）、新建、调度、签收、取消、CSV 导出
- 调度中心：全部调度记录（发车/ETA/到达/状态）
- 在途跟踪：按运单号查询 GPS 轨迹流
- 客户管理：客户档案、信用额度、月结/现结
- 车辆管理：车辆档案、载重容积、维保/保险到期日
- 司机管理：司机档案、驾照到期、累计运单里程
- 线路管理：起点终点、里程、标准时长、基础运价（分/km）
- 财务结算：应收/应付/毛利汇总、结清操作、CSV 导出
- 油耗管理：按车辆登记加油记录
- 风险预警：逾期运单/维保/驾照/客户欠款四类扫描与处理
- 系统管理：用户、API Key、公告、审计日志

## 5. 金额口径

系统内部金额统一使用「分」（整数化存储，Decimal 精确计算）：
- 运单报价 48000 = ¥480.00
- 线路基础运价 60 = 0.60 元/吨·km（按重模式）
- 结算页展示原始分值，方便对账

## 6. 系统对接

- 「系统管理 → API Key」生成密钥（明文仅显示一次）
- 外部系统以 `X-Api-Key` 头调用全部只读与授权接口
- 写接口支持 `Idempotency-Key` 幂等
- 车载终端可批量 POST /api/trackings 上报 GPS
- 财务系统可轮询 GET /api/sync?since= 增量拉取
- 详见《飞运 TMS 接口契约》文档

## 7. 部署运维

- 服务端口 8026，nginx 反向代理 /tms/
- systemd 单元 feiyun-tms；数据库 data/feiyun.db（WAL）
- 日志：journctl -u feiyun-tms；审计日志见「系统管理 → 审计日志」
- 备份：定期拷贝 feiyun.db（含 -wal 文件）即可

## 8. 常见问题

- **调度时提示"车辆非空闲"**：该车已有在途运单，先签收/撤销对应运单，或换车。
- **提示"运单状态为 xxx，不可调度"**：只有「待调度」运单可调度。
- **结算金额与报价不一致**：签收时按实际里程自动计算运价，取报价与计算价中的报价优先；可在结算页手工调整（仅待结状态）。
- **离线 DEMO**：双击打开 demo 目录下单文件 HTML，右上角可切换角色视角，数据为真实快照只读。
